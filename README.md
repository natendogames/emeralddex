# Emerald Completion Dex

A phone-friendly, offline-capable 100% completion guide for Pokémon Emerald. It is built on the same code as the
[FireRed/LeafGreen Completion Dex](https://github.com/natendogames/frlgdex).

- **Routes**: all 87 Hoenn locations in story order, plus the post-game areas and event islands. Each location has:
  - walkthrough steps
  - every trainer, with their party, levels, moves, weaknesses, prize money and rewards, and a damage estimate for each of your Pokémon against each of theirs. Rival teams follow your starter and whether you play as May or Brendan.
  - wild Pokémon
  - items on the ground and hidden items
  - NPC gifts and in-game trades

  All of these are checklists.
- **Story progress**: fishing, Surf, Dive and Rock Smash encounters stay under "come back later" until you have the rod or HM. Swimmers wait until you can Surf. Rooms that open later in the story are gated the same way, such as the Abandoned Ship's hidden floor or the post-game Safari Zone areas. When your team has no good answer to a trainer's Pokémon, the app suggests one you could have caught by that point. Suggestions are based on damage with real moves and levels, and never include legendaries.
- **Pokédex**: Hoenn 202 or National 386, showing where to catch each one, what to evolve it from, or where to trade it from.
- **Battle plan**: enter your team to see who to send out against each Gym Leader, rival and Wally battle, Team Magma and Team Aqua boss, the Elite Four and Wallace.
- **Team plan**: the best team at every point of the game for your starter. Before each key battle it lists, as checkboxes:
  - who to catch or box
  - who evolves
  - which moves and TMs to teach
  - the lineup and who to lead with
- **Catch plan**: shows the odds with every ball the shops sell by that point, including Net, Nest, Dive, Repeat and Timer Balls. It then gives a step-by-step plan that uses your team's moves. The Master Ball is never planned for.
- **Reference pages, progress, shops and tutors, item pages and tools**: these are the same as the FireRed/LeafGreen app. Instead of the Kanto-only trackers there are Match Call rematch tiers, the Emerald story checklist and the Mauville Game Corner prizes. Save import reads Emerald `.sav` files.
- Progress is stored on the device, with backup export and import.
- Optional cloud sync between devices, keyed by an email address with no password. It uses the FireRed/LeafGreen app's Cloudflare Worker, and Emerald progress is stored under a separate key, so the two games never overwrite each other.

The app is plain HTML, CSS and JS with no build step, hosted on GitHub Pages. To run it locally, use `python3 -m http.server` in this folder and open http://localhost:8000.

## Data

`data/` is generated by `scripts/build_data.py` from the [pret/pokeemerald](https://github.com/pret/pokeemerald) decompilation. This means encounter tables, item placements, NPC gifts, trades, trainer parties, shops, tutors and Match Call rematches all match the game itself:

```
git clone --depth 1 https://github.com/pret/pokeemerald /tmp/pokeemerald
python3 -I scripts/build_data.py /tmp/pokeemerald data
```

`data/walkthrough.json` holds the hand-written story steps, and the script doesn't overwrite it. These steps are Draft until they have been checked in play.

Where the decomp doesn't say when something becomes available, the build script states it in its own tables:
- `AREA_AFTER`, `GIFT_AFTER` and `STATIC_AFTER` cover rooms, gifts and static encounters that open later in the story.
- `MIN_STAGE` covers Route 103's east side, which you reach from Route 110.
- Swimmers are placed after Surf.
- Each trainer is placed at the first key battle whose ace is within five levels of the trainer's own ace.

The file layout is the same as in the FireRed/LeafGreen app. Rows have no `versions`, rival battles add `byStarterBrendan` where Brendan's team differs from May's, and Pokédex rows carry their `hoenn` number.

## Team planner

```
node scripts/team_planner.js --out docs/team-guide.md --stages-out docs/team-stages.md --app-json data/team-plan.json
```

This scores candidate teams against every trainer up to the Champion using the Battle plan's damage engine, counting TMs and HMs as well as level-up moves. It writes the most viable six for each starter, plus the stage-by-stage plan used by the Team plan page. Run it again after any change to the data or the engine.

## Tests

These are the same suites as the FireRed/LeafGreen app, and GitHub Actions runs them on every push and pull request:
- `node tests/audit_battles.js` checks every trainer's catch suggestions against a brute-force search. It also checks the HM and post-game gating, and that nothing counts as caught before you have Poké Balls.
- `node tests/team_plan.js` checks the Team plan.
- `node tests/features.js` checks:
  - every page renders
  - catch plans only use balls sold by that point
  - Net, Nest and Dive Ball multipliers
  - Emerald save import
  - search
  - calculators
- `node tests/walkthrough.js` checks that every place has walkthrough steps, that every `{gift:}`, `{trainer:}`, `{loc:}`, `{mon:}` and `{item:}` link in a step points at real data on that page, and that pages render cleanly.

Walkthrough steps live in `data/walkthrough.json`. Places listed in its `_checked` map were checked against the decomp's event scripts; the rest show a Draft tag.

Progress keys are `dex:<number>` for Pokémon and `<location-id>:item:<id>` or `<location-id>:gift:<id>` for checklists, so keep ids stable.
